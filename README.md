# انتقاء الحركية قصيرة المدى في الخارج

برنامج يساعد نائب العميد أو رئيس القسم المساعد المكلف بما بعد التدرج والعلاقات الخارجية على دراسة طلبات التربصات في الخارج. البرنامج يصنّف الملفات وينقّطها ويرتّب المترشحين وفق **القرار رقم 345 المؤرخ في 09 مارس 2026** الذي يحدد معايير الانتقاء للقبول في برنامج الحركية قصيرة المدى في الخارج، ووفق شبكات التقييم الملحقة به.

يعمل البرنامج **بدون إنترنت**، وتبقى البيانات على جهاز المستخدم.

## التنصيب

| النظام | الملف | ملاحظات |
|---|---|---|
| Windows | `dist/tarabbusat-1.0.0-win-x64-portable.exe` | نسخة محمولة لا تحتاج تنصيبا: انقر مرتين لتشغيلها |
| Linux | `dist/tarabbusat-1.0.0-linux-x86_64.AppImage` | امنحه صلاحية التنفيذ (`chmod +x`) ثم شغّله |
| macOS / مثبّت Windows | عبر GitHub Actions (`.github/workflows/build.yml`) | ملف ‎.dmg‎ لا يُبنى إلا على جهاز Mac |
| أي نظام (حتى الهاتف) | مجلد `app/` | افتح `app/index.html` في المتصفح، أو انشره على خادم ثم ثبّته كتطبيق ويب (PWA) |

للبناء على جهازك:

```bash
npm install
```

```bash
npm run dist:win
```

استبدل `dist:win` بـ `dist:mac` أو `dist:linux` حسب النظام.

## ما يقوم به البرنامج

1. **11 فئة**:
   - 9 شبكات تنقيط منقولة حرفيا من الملاحق.
   - فئتان بدون تنقيط: البرنامج الخاص، وطلبة ماستر 2.

   | الرمز | الشبكة |
   |---|---|
   | ج-1 | التظاهرات العلمية الدولية (الجامعة) |
   | ج-2 | الإقامة العلمية ذات المستوى العالي (الجامعة) |
   | ج-3 | تربص تحسين المستوى: طلبة الدكتوراه والأساتذة المساعدون |
   | ج-4 | الموظفون الإداريون والتقنيون (الجامعة) |
   | م-1 | التظاهرات والإقامات العلمية: الباحثون الدائمون |
   | م-2 | التربصات: الباحثون الدائمون |
   | م-3 | الإداريون بمراكز البحث |
   | م-4 | التقنيون بمراكز البحث (شعبة الهندسة) |
   | م-5 | التقنيون بمراكز البحث (شعبة التطوير التكنولوجي) |
   | خ-1 | البرنامج الخاص (حسب شروط الوصاية، بدون تنقيط) |
   | خ-2 | طلبة ماستر 2 في التكوين المشترك (متابعة فقط) |

2. **التنقيط الآلي**. يطبّق البرنامج:
   - الحدود القصوى لكل بند.
   - نسب مركز المترشح بين المؤلفين: 100% للأول، 90% للثاني، 80% للثالث، 70% للرابع، 50% للخامس فما فوق.
   - شرط تسمية المؤسسة في المقال.
   - صيغ الاستفادات السابقة: ‎3-n‎ و‎4-n‎ و‎5-n‎ و‎N-n‎.
   - علاوة التأهيل الجامعي.
   - خصم 5 نقاط عن كل تربص سابق للموظفين الإداريين والتقنيين.
3. **فحص الأهلية**:
   - الجنسية الجزائرية والوثائق المطلوبة لكل فئة (المادة 14).
   - مدة الحركية (المادتان 12 و13).
   - الاستفادة مرة واحدة في السنة المالية، مع الاستثناءات (المادة 11).
   - التسجيل المنتظم في الدكتوراه ابتداءً من التسجيل الثاني.
   - رفض عضو لجنة الانتقاء إن ترشح.
4. **الترتيب**:
   - حسب الفئة، ويمكن التقسيم أيضا حسب الرتبة أو القسم أو التخصص أو صنف الحركية.
   - عند تحديد عدد المناصب يظهر المقبولون وقائمة الاحتياط.
   - تبقى للجنة إمكانية القبول أو الرفض المبرر.
5. **الوثائق**:
   - طباعة سلم التقييم الفردي بنفس شكل الملحق، ومحضر الترتيب، وسلم فارغ.
   - تصدير إلى Excel، واستيراد قائمة المترشحين من Excel.
6. **حصص المادة 5**: حاسبة توزيع 80% و10% و10% من المناصب والميزانية.
7. **المتابعة بعد العودة** (المواد 16 إلى 19): وثائق العودة، والعرض أو المحاضرة، والتنبيه إلى التأخر.
8. **النسخ الاحتياطي**: تصدير البيانات واسترجاعها (JSON) لنقلها إلى جهاز آخر.

## تفسيرات اعتمدناها حيث النص غير صريح (قابلة للمراجعة)

جميعها معرّفة في ملف واحد هو `app/js/grids.js`، ويمكن تعديلها بسهولة.

- **«جوائز / براءة اختراع 10 نقاط»** (ج-1، ج-2) و**«جوائز 5 نقاط»** (ج-3): تحتسب **لكل جائزة**.
- **«الإشراف على مشروع حصل على وسم لابل 05 نقاط»**: تحتسب لكل مشروع.
- **«تدريس محاضرة في جذع مشترك 04 نقاط (احتساب محاضرتين على الأكثر)»**: 4 نقاط لكل محاضرة، بحد أقصى محاضرتان (8 نقاط).
- **المداخلات** (ج-1، ج-2): يطبَّق الحد الأقصى (4 مداخلات) على كل سطر.
  - في ج-3 يطبَّق أيضا حد إجمالي قدره 4 مداخلات دولية، كما ورد في الشبكة.
- **«عدد التربصات خلال 5 سنوات (n-5)»**: قرأناها ‎5-n‎، على غرار ‎3-n‎ في باقي الشبكات.
- **م-2 «4-ن (حد أقصى 03) / 5-ن (حد أقصى 04)»**: تختار اللجنة قيمة N، والنتيجة محصورة بين 0 و‎N-1‎.
- **الفصل عند تساوي المجموع** (غير محدد في القرار): يكون بالترتيب التالي:
  1. الحيازة على نجوم، للطلبة.
  2. الأقل استفادة سابقة.
  3. الرتبة الأعلى.

  تظهر علامة «تساوٍ» لتنبّه اللجنة. ويمكن جعل أولوية النجوم مطلقة من الإعدادات.
- **أجل إيداع وثائق العودة** (افتراضيا 30 يوما): أجل داخلي قابل للتعديل، لأن القرار لا يحدده.

> النص الرسمي للقرار هو المرجع دائما. صفحة «ملخص القرار» في البرنامج ملخص عملي فقط.
